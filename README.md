# BMAD Framework

BMAD Methodology — Blueprint, Mapping, Analysis, Design fuer DEVKiTZ.

## Features

- 7 specialized AI agents: James Guardian, PM, Architect, Developer, Reviewer, Tester, Dokumentar
- Ralph-Loop execution pipeline preventing context drift
- 4-phase methodology: Blueprint → Mapping → Analysis → Design
- CodeRabbit QA integration for automated code review
- MCP server support for agent communication

## Tech Stack

Node.js 18+ · JavaScript ES6+ · DuckDB · MCP Server · OpenRouter

## Quick Start

```bash
git clone https://github.com/D-VKITZ/bmad-framework.git
cd bmad-framework
npm install
# Start a Ralph-Loop cycle
node scripts/start-loop.js
```
